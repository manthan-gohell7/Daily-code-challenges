# Daily Code Challenges

This repository is my daily coding challenge journal.

The goal is not only to solve problems, but also to develop logical thinking, problem-solving skills, programming fundamentals, and consistency through deliberate practice.

## Platforms

Current platforms:

- freeCodeCamp

Additional platforms may be added in the future as the repository grows.

## Repository Structure

### PROGRESS.md

Tracks all completed challenges in chronological order.

Contains:
- Total challenges solved
- Challenge numbering
- Date
- Platform
- Challenge title
- Topics covered
- Milestones and statistics

This file serves as the high-level index of the repository.

### LEARNING_LOG.md

Records observations and lessons learned while solving challenges.

Entries may include:
- What I Learned
- Challenge
- Takeaway
- Mistake and Fix (when applicable)

This file serves as a reflection journal for my learning journey.

### Platform Folders

Each platform has its own folder.

Example:

- free_code_camp/

Each solution is stored as an individual file.

## File Naming Convention

Each challenge file follows this format:

YYYY_MM_DD_CHALLENGE_NUMBER_TITLE.js

Example:

2026_06_02_001_vowel-balance.js

Where:
- YYYY_MM_DD = date solved
- 001 = challenge number
- vowel-balance = challenge title

The challenge number is global across the entire repository and represents the overall count of completed challenges.

## Solution File Structure

Every challenge file contains:

- Challenge Number
- Date
- Platform
- Title
- Topics
- Description
- Approach
- Notes

followed by the solution implementation.

## My Goal

This repository is not intended to be a collection of answers.

It is a public record of:
- Consistent practice
- Logical thinking development
- Learning progress
- Problem-solving experience

## Rules I Follow

- One challenge = one file
- Consistent naming conventions
- Clean and readable code
- Reflection through learning logs
- Regular commits whenever possible
- Focus on understanding the solution, not just completing the challenge
