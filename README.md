# Daily Code Challenges

This repository is my daily practice log for solving coding challenges consistently.

I use this repo to improve:
- problem solving
- logical thinking
- programming fundamentals
- clean code habits
- consistency over time

## Platforms

I mainly practice on:
- freeCodeCamp

## Folder Structure

Each platform has its own folder.

Example:
- `free_code_camp/`

## File Naming Format

Each solution file follows this pattern:

`YYYY-MM-DD_challenge-number_short-title.js`

Example:
- `2026-06-02_001_vowel-balance.js`

## Inside Each Solution File

Every solution file includes a short comment header with:
- Date
- Platform
- Challenge
- Description
- Approach
- Notes

## My Goal

This repo is not just a collection of answers.  
It is a record of daily problem solving and gradual improvement in logical thinking.

## Rules I Follow

- One challenge = one file
- Clean and readable code
- Short notes on approach
- Consistent naming
- Daily commits whenever possible
